# Geo Data

`korea_places.csv`는 랜딩 지도에서 사용자가 클릭한 좌표에 가장 가까운
시/군 대표 지명을 붙이기 위한 MVP용 좌표 데이터다.

- 좌표계: `EPSG:4326`
- 용도: 지도 클릭 지점의 기본 이름 추천 및 metadata 기록
- 비용/입지/행정 경계 판정용 아님
- 고도는 포함하지 않으며, 기존 설치 지점 계약의 `elevation_source="not_queried"`를 유지한다.

좌표는 국내 주요 시/군 대표점 중심으로 정리했다. 광역시뿐 아니라 구미,
상주, 거창, 해남 같은 중소도시와 군 단위도 포함한다.

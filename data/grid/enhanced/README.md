# Grid enhanced CSV

이 디렉토리는 13단계의 확장 Grid 데이터셋이다.

- `nodes.csv`: 기본 발전소 12개와 송전탑/부하 노드 24개
- `lines.csv`: 권역 backbone, 발전소 연결, 해저/장거리 후보 선로를 포함한 양방향 송전망
- `plants.csv`: 발전소별 설비 용량, 연료원, 가용률, 운영비 계수
- `tower_candidates.csv`: 송전탑 후보별 지형/비용/리스크/접근성 속성

현재 값은 공개 실계통 원장을 복제한 데이터가 아니라, MVP 검증용으로 만든 현실성 강화 synthetic 데이터다. 실제 설비 인허가, 송전망 운영, 입지 판단의 최종 기준으로 쓰면 안 된다.

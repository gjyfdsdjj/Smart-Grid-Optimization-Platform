# Neural GNN model artifacts

This directory stores the PyTorch Neural GNN beta artifacts generated by
`src.engine.forecast.neural_gnn_forecaster.NeuralGNNForecaster`.

- `model.pt`: trained PyTorch checkpoint.
- `training_history.csv`: epoch-level train/validation loss.
- `metadata.json`: model configuration and evaluation metrics.
- `evaluation_summary.json`: recursive 24h holdout MAE/RMSE/MAPE summary from processed GridNode history.
- `node_error_summary.csv`: node-level holdout error summary.

재학습 명령:

```bash
PYTHONPYCACHEPREFIX=/tmp/sgop_pycache .venv/bin/python scripts/train_neural_gnn_from_processed.py --epochs 5 --batch-size 256
```

이 모델은 `data/processed/grid_node_load_history.csv`의 송전탑 부하 이력과
`data/grid/enhanced/lines.csv`의 GridLine adjacency를 함께 사용한다.
